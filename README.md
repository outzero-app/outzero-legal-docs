# Outzero Legal Docs

Public legal documents for Outzero in Spanish and English.

## Structure

- `es/privacy-policy.md`
- `es/cookies-policy.md`
- `es/terms-of-use.md`
- `en/privacy-policy.md`
- `en/cookies-policy.md`
- `en/terms-of-use.md`

## Intended usage

These files are designed to be consumed remotely by Outzero clients using stable raw GitHub URLs.

Base repository URL:

`https://github.com/outzero-app/outzero-legal-docs`

Raw examples:

- `https://raw.githubusercontent.com/outzero-app/outzero-legal-docs/main/es/privacy-policy.md`
- `https://raw.githubusercontent.com/outzero-app/outzero-legal-docs/main/en/privacy-policy.md`

## Update policy

Any change to these documents should be committed directly in this repository so clients can fetch the latest version automatically.
